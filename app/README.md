# SkipTV для Apple TV

Свой клиент Plex для tvOS: медиатека, плеер на mpv (MKV, HEVC/Dolby Vision, DTS/TrueHD,
PGS/SRT — без транскодирования) и автопропуск заставок и титров по данным детектора
из [`detector/`](../detector).

## Что умеет

- Вход через аккаунт Plex кодом на `plex.tv/link`, выбор сервера, автоматический выбор
  адреса (сначала локальный, потом внешний, потом relay).
- Главная: «Продолжить просмотр», недавно добавленное по каждой медиатеке. Вкладки
  «Фильмы» и «Сериалы» (по библиотекам сервера), страницы фильма и сериала с сезонами
  и сериями, отметки просмотренного (долгое нажатие на серию — отметить вручную).
- Плеер: direct play оригинального файла через mpv (MPVKit, `gpu-next` + MoltenVK,
  аппаратное декодирование VideoToolbox). Русская аудиодорожка по умолчанию;
  субтитры: при русской озвучке — только форсированные русские, иначе — полные русские.
- Прогресс уходит в Plex (`/:/timeline` каждые 10 с и при паузе/остановке), отметка
  «просмотрено» — при начале финальных титров или на 90 %. «Продолжить с …» при открытии.
- Пропуск (Настройки → Пропуск):
  - **Автоматически** (по умолчанию): заставка и титры пропускаются сами, кроме первой
    серии сезона — там кнопка «Пропустить заставку» / «Следующая серия».
    Финальные титры → карточка «Следующая серия через 5» с кнопками «Смотреть» и «Титры».
    Если после титров есть ещё больше 20 с (сцена после титров) — перематывается только
    до конца титров. Пересказ (recap) и анонс (preview) — всегда кнопкой.
  - **Кнопкой**: всегда кнопка «Пропустить …».
  - **Выключено**.
  - Детектор недоступен или серия не размечена — видео просто играет.

### Пульт в плеере

| Кнопка | Действие |
|---|---|
| Нажатие тачпада | показать панель / пауза, если панель видна; на кнопке «Пропустить» — пропустить |
| Play/Pause | пауза |
| ◀ / ▶ | −10 с / +30 с |
| ▼ | аудиодорожки и субтитры |
| Menu | закрыть панель дорожек / отменить «Следующую серию» / выйти из плеера |

## Установка на Apple TV (бесплатно, без Apple Developer Program)

Нужны Mac с Xcode 16 или новее и Apple TV 4K (tvOS 17+) в той же сети.

1. Склонируйте репозиторий и откройте проект:
   ```sh
   git clone https://github.com/emildeev/skiptv.git
   open skiptv/app/SkipTV.xcodeproj
   ```
   Xcode сам скачает зависимости (MPVKit — около 300 МБ, первый раз несколько минут).
2. Добавьте Apple ID: **Xcode → Settings → Accounts → +** → Apple ID (обычный, бесплатный).
3. Свяжите Apple TV с Xcode: на Apple TV **Настройки → Пульты и устройства → Приложение
   «Пульт» и устройства**; в Xcode **Window → Devices and Simulators** — Apple TV появится
   в списке, нажмите **Pair** и введите код с экрана телевизора.
4. Подпись: выберите проект **SkipTV** → таргет **SkipTV** → вкладка **Signing &
   Capabilities** → **Team** = ваш «(Personal Team)».
   Если Xcode пишет, что bundle id занят, поменяйте **Bundle Identifier** на свой,
   например `com.<ваше-имя>.skiptv`.
5. Вверху выберите схему **SkipTV** и свою Apple TV как устройство → **Run** (⌘R).
   Схема собирает Release-сборку: так плеер работает быстрее.

### Через 7 дней

Бесплатная подпись живёт 7 дней, потом приложение перестаёт запускаться (данные и вход
сохраняются). Чтобы продлить — снова пункт 5: подключите Apple TV, `git pull` при
желании и **Run**. Переустанавливать с нуля не нужно.

### Чтобы не менять проект руками

Выбор команды в Xcode меняет `project.pbxproj`, и `git pull` может конфликтовать. Вместо
этого можно создать `app/Config/Local.xcconfig` (он в `.gitignore`):

```
DEVELOPMENT_TEAM = ABCDE12345
SKIPTV_BUNDLE_ID = com.yourname.skiptv
```

Team ID видно в **Xcode → Settings → Accounts** (или в Keychain, в сертификате
«Apple Development»).

## Настройки приложения

- **Адрес детектора** — по умолчанию `https://skiptv.emill.keenetic.pro`. Запросы идут с тем
  же токеном Plex (`X-Plex-Token`).
- **Адрес** сервера — автоматически или конкретный (локальный `http://…:32400` или внешний).
- **Облегчённая отрисовка** — mpv `profile=fast`, если 4K подтормаживает.

## Разработка

```
app/
  project.yml              XcodeGen-описание проекта (источник правды)
  SkipTV.xcodeproj         сгенерирован из project.yml и закоммичен
  Config/SkipTV.xcconfig   общие настройки, подключает Local.xcconfig
  SkipTV/                  приложение: экраны SwiftUI, плеер (MPVPlayer, PlayerModel)
  Packages/SkipTVKit/      логика без UI: API Plex, детектор, политика пропуска,
                           следующая серия, прогресс, выбор дорожек + тесты
  scripts/make_icons.py    генератор иконки и Top Shelf
```

- Поменяли `project.yml` или добавили файлы — `brew install xcodegen && xcodegen generate`
  в `app/` и закоммитьте `SkipTV.xcodeproj`. CI проверяет, что проект совпадает с
  `project.yml`.
- Тесты логики: `cd app/Packages/SkipTVKit && swift test` (на Mac, без симулятора).
- CI (`.github/workflows/app.yml`): `swift test` и сборка приложения под tvOS Simulator без
  подписи.

## Ограничения первой версии

- HDR и Dolby Vision показываются через тонмаппинг mpv в SDR: Apple TV не переключается в
  режим HDR/DV, нет подстройки частоты кадров под видео.
- Звук mpv декодирует сам (TrueHD/DTS → PCM): Atmos и DTS:X без объектов, без битстрима.
- Перемотка — шагами ±10/30 с, без свайпа по таймлайну и превью кадров.
- Нет поиска, коллекций, плейлистов, музыки и фото; только библиотеки фильмов и сериалов.
- Пропуск работает, только если детектор уже разметил серию.
